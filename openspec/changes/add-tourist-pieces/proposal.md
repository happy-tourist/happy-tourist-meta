## Why

На статическом поле «Счастливый турист» ещё нет игроков: при входе в комнату нужно раздать до четырёх уникальных фигурок-туристов по сторонам доски и показать seated-игроку «своего» туриста под полем, а остальных оставить гостями — без ходов и правил партии.

## What Changes

- В room `tourist` появляется авторитетная рассадка: до 4 seated-игроков получают уникальный вид туриста и уникальную сторону со случайной стартовой клеткой; после четвёртой раздачи партия считается стартовавшей и новым клиентам фигурки не выдаются.
- На экране Game все клиенты видят расставленные фигурки на доске; seated-игрок дополнительно видит под доской изображение своего туриста; гость strip не видит.
- До старта выход seated освобождает вид и сторону для следующих join; после старта раздачи новым не возобновляются; фигурка ушедшего снимается с sync.
- Клиентов в комнате без лимита (гости могут смотреть); seated максимум 4.

## Scope

- **Capability ID:** `game/pieces` (новый); `game/board` (модификация — доска показывает фигурки).
- **Пакеты:** client (рендер фигурок + strip «мой турист»); server (рассадка, sync state, старт по 4 seated).
- **Client:** экран Game — фигурки на стартовых клетках по sync; strip только для seated; без UX хода.
- **Server:** room `tourist` — назначение touristId / side / start cell; флаг старта при 4 seated; leave до/после старта; без лимита `maxClients` сверх политики «игроков ≤ 4».
- **Контракт:** расширенный synced state комнаты `tourist` (seats/pieces + started); game action messages по-прежнему нет.

## Out of scope

- Ходы, валидация перемещений, очередь ходов, задания на тайлах.
- Статус «турист дошёл до центра» и любой progress UI кроме текущего «мой турист» под доской.
- Политика «продолжают втроём» / forfeit / reconnect после старта (кроме: не раздавать новым; убрать фигурку ушедшего из sync).
- Выбор/подсветка клеток, клики по фигуркам.
- Новые HTTP API, изменения auth / lobby listing (кроме косвенного отображения status комнаты при необходимости).
- Загрузка или генерация PNG ассетов (файлы `tourist1`…`tourist4` уже в client).

## Capabilities

### New Capabilities

- `game/pieces`: рассадка до 4 туристов в room `tourist` (уникальный вид и сторона, случайная стартовая клетка), старт при 4 seated, гости без strip, leave до/после старта.

### Modified Capabilities

- `game/board`: снять запрет «no player pieces»; доска SHALL показывать синхронизированные фигурки туристов на стартовых клетках, оставаясь неинтерактивной.

## Impact

- Client: Game UI (фигурки + strip), чтение sync state в game store; ассеты туристов уже лежат в client.
- Server: product schema вместо scaffold; логика seat assign / start / leave в room `tourist`; mocha-тесты на seating.
- Main specs: появится `game/pieces`; обновится `game/board` после sync/archive.
