## Why

Сейчас один легальный шаг сразу передаёт ход следующему: партия — «по клетке за раз», без ресурса и без заданий на коричневых тайлах. Нужна экономика **шагов** и **просмотров**, peek под тайлом (пока happy-path Correct/Wrong) и явный/авто конец хода — иначе нельзя строить ловушки, покупки и вопросы поверх поля.

## What Changes

- **BREAKING:** успешный move **больше не** передаёт ход; ход кончается кнопкой «Завершить ход», таймером 60 с, или когда нет доступных действий.
- У каждого seated — приватные счётчики **шагов** и **просмотров** (старт 0/0; при получении хода в мульти **+1 / +1**); 1 клетка = −1 шаг; peek = −1 просмотр.
- На своём туриста на живом коричневом `*` — иконка глаза; модалка награды 1–3; кнопки «Правильно» / «Неправильно»; **тайл снимается только при «Правильно»** (дыра у всех, клетка проходима); при «Неправильно» / timeout / leave / endTurn с открытой модалкой — только −peek, тайл и награда остаются; за ход не больше одного peek.
- Рядом со своим аватаром — счётчики и кнопка «Завершить ход» (в соло кнопка не нужна).
- Соло (один non-finished): шаги и просмотры → **∞**, без лимита peek и без +1 за ход; ограничение только 5:00 + обычный финиш.
- После успешного хода **фокус остаётся** на ходившем туристе: при оставшихся шагах — красные клетки куда идти; при оставшихся просмотрах и живом `*` под ногами — глаз (без повторного клика). Финиш на центре / finished — selection сбрасывается.
- Анимация «+N» в счётчики шагов/просмотров — около **2 с** (медленнее прежнего ~0.85 с).

## Scope

- **Пакеты:** client + server (room `tourist`); meta skills под контракт.
- **Capability ID:**
  - `game/move` — бюджеты шагов/просмотров; move не advance’ит ход; end-turn; авто-конец; соло ∞; timeout/leave/endTurn с открытой peek = как Wrong (без снятия тайла); keep-focus после move + red hints;
  - `game/board` — преген наград на `*`; peek UX; снятие тайла **только при Correct**; Wrong KEEP; глаз без re-select если focus на живом `*`;
  - `game/presence` — приватные счётчики у своего маркера; кнопка «Завершить ход»; соло-модалка про ∞; +N anim ~2 с.
- **Экран:** Game (seated); spectators видят дыры на доске, не видят чужие счётчики.
- **Контракт:** room `tourist`; messages move / peek-answer / end-turn (+ private steps/peeks владельцу); sync снятых task-клеток.

## Out of scope

- Вопросы/ловушки на тайлах (только stub Correct/Wrong).
- Покупка просмотров/ловушек за шаги.
- Смена геометрии layout / числа `*` / таймеров 60 с и 5 мин.
- Публичный показ чужих шагов/просмотров.
- Кап «добить до 10» в соло (отклонён).
- Новые HTTP / auth / lobby.
- Ambient-подсветка всех peekable туристов/клеток (только глаз над выбранным на живом `*`).
